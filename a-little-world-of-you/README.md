# A Little World of You

A small, personal, single-page website: a calm welcome, a gallery of photographs, and a letter.
Built with plain HTML, CSS and vanilla JavaScript. No frameworks, no trackers, no external requests.
**Designed for a phone first** (she will most likely open a WhatsApp link); tablets and laptops get the same experience with more room.

> Status: first working version. Names, welcome message, gallery wording and the whole letter are
> **placeholders in [square brackets]** until you supply the real words. No music is included.

---

```
├── docs/ENGINEERING_REPORT.md  design decisions, accessibility, performance, limitations
├── README.md
└── .gitignore
```

## Run it on your computer

Browsers restrict some features on `file://`, so use a tiny local server. From the project folder:

```
python3 -m http.server 8000
```

Open <http://localhost:8000>. To try it on your phone, connect the phone to the same Wi-Fi, find your
computer's local IP address (for example `192.168.1.20`) and open `http://192.168.1.20:8000` on the phone.

## Change the words (name, welcome, letter)

Open **`js/content.js`**. Everything in `[square brackets]` is a placeholder.

| To change | Edit |
|---|---|
| Her name, welcome message, button label | `welcome.name`, `welcome.message`, `welcome.buttonLabel` |
| Gallery heading / optional intro line | `gallery.title`, `gallery.intro` |
| Letter heading, quiet line before it | `letter.title`, `letter.preface` |
| The letter | `letter.salutation`, then one entry in `letter.paragraphs` per paragraph |
| Sign-off | `letter.closing`, `letter.signature` |

Put `*asterisks*` around words to set them in **Fraunces Italic**, for example
`"You make *ordinary days* feel lighter."`. Use italics deliberately; the body of the letter should stay easy to read.

## Photographs

Current working set: photo 9 (welcome), then 3, 4, 6, 7, 2, 11, 5, 10 in the gallery.
Left out on purpose: photo 1 (another person), photos 8 and 12 (night photos), and the un-blurred version of 5.

**Add or replace a photo**

1. Put the original in `source-photos/` named `photo-NN.jpg` (for example `photo-12.jpg`).
2. Run `pip install pillow` once, then `python3 tools/optimize_images.py`.
   This fixes rotation, **removes all metadata (GPS, device, dates)**, and writes responsive WebP files
   plus `js/photo-manifest.js`.
3. Add a line to `gallery.photos` in `js/content.js`:
   `{ id: "photo-12", size: "full", align: "center", mat: false, caption: "", alt: "Describe the photo." }`

**Reorder**: move the lines in `gallery.photos`. **Remove**: delete the line.
**Change the welcome photo**: change `welcome.photo.id`. The welcome photo is a crop of photo 9
(`photo-09-hero`, defined in `tools/optimize_images.py`); adjust the crop fractions there if you want a different framing.

**Per photo options**: `size` ("full" or "inset"), `align` ("left", "right", "center"), `mat` (soft ochre frame),
`caption` (leave `""` for none; use captions only where they add meaning), `alt` (please keep it descriptive for screen readers).

If a photo file is missing, the page shows a clear box naming the missing file instead of a broken image.

## Adding music

No music is included, and none is loaded or played until you configure it.

1. Put your licensed track at **`assets/music/background.mp3`** (a quiet instrumental, ideally 1-3 MB).
2. In **`js/content.js`**, change `music.enabled` from `false` to `true` (look for `TODO: ADD BACKGROUND MUSIC HERE`).
3. Optional: adjust `music.volume` (0 to 1) and `music.fadeInSeconds`.

How it behaves once enabled: nothing plays on load. Music starts when she taps **Come in** (browsers allow sound
after a tap). A round play/pause button appears at the bottom-right. The file is not downloaded until playback starts.

**Test it:** serve the site (see above), open it, check the music button is visible, tap **Come in** and confirm the
track fades in, tap the button to pause and play, and switch to another app and back (it pauses when hidden and
resumes if you had not paused it).

Notes: iPhones ignore programmatic volume, so master the track quietly. Make sure you have the right to use the track
(commercial songs can be taken down or cause legal problems if the site is public).

## How to test

Run these checks in a phone-sized browser window (browser dev tools "device mode") and on a real phone:

- Widths 360, 375, 390, 430 px: no sideways scrolling, nothing clipped or overlapping.
- The welcome fits one screen and **Come in** is easy to tap.
- Tap a photo: it opens large; swipe left/right or use the arrows; close with the X, the dark area, or Esc.
- Keyboard: Tab through the page (focus is always visible), arrow keys in the viewer, Esc closes and returns focus.
- Turn on "Reduce motion" in your phone or computer settings: no entrance animations, no smooth scrolling.
- Throttle the network to "Slow 4G" and check the first screen appears quickly.
- Open the link inside WhatsApp's in-app browser on Android and iPhone (these behave differently from Chrome/Safari).
- Read the letter on a phone with real text (not placeholders) before you send the link.

## Prepare for GitHub (do not publish yet)

1. Create a **private** repository named `a-little-world-of-you`.
2. Check `.gitignore` is present: it keeps `source-photos/` (your originals) out of the repository.
3. Commit only the optimised files in `assets/images/`.
   Git history is permanent: a photo committed once stays in history even if you delete it later.
4. **Hosting decides privacy, not the repository.** A private repo does not make a deployed site private.
   Anything on GitHub Pages (or most static hosts) is reachable by anyone with the link, and a free-plan
   private repository may not be able to publish Pages at all; check GitHub's current documentation.
   If the photos or letter would embarrass either of you if forwarded, choose a host with real access control.
   The page already asks search engines not to index it (`noindex`) and sends no referrer,
   but that only prevents indexing; it is not access control. Use a hard-to-guess address.
5. Consider taking the site down after a set time.
